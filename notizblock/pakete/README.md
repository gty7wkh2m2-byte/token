# Update-Pakete (Rückweg Claude Code / Routine → Werkzeug)

Format: `{"paket":"inbox|bauplan","nodes":[…],"bauplan":{…},"settings":{…},"register":{…},"log":["…"]}`.
Import im Werkzeug: Backend › Export / Import › Datei wählen oder JSON einfügen. Knoten werden per `id` aktualisiert oder neu angelegt; Bauplan-Einträge per `id`/`nr`.
Dateiname: `bauplan_JJJJ-MM-TT_HHMM.json` oder `inbox_JJJJ-MM-TT_HHMM.json` (Europe/Berlin).
